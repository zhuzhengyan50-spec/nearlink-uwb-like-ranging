# 定位算法说明

## 当前实现

设第 (i) 个 anchor 坐标为 \(\mathbf a_i\)，测得距离为 \(d_i\)，目标位置为 \(\mathbf p\)。程序求解的基本问题是：

\[
\min_{\mathbf p}\sum_i(\lVert\mathbf p-\mathbf a_i\rVert-d_i)^2
\]

`algorithm.py` 采用两步实现：

1. 以第一个有效 anchor 为参考，将平方距离方程相减，使用 `numpy.linalg.lstsq` 得到无约束线性最小二乘（ULS）初值。
2. 在该初值或上一帧位置上执行**一次** Gauss–Newton 更新。

这里特意写明“一次”：当前代码不是循环迭代到收敛的完整 Gauss–Newton 优化器。上一帧位置仅作为热启动初值；位置 Kalman 是随后可选的显示/轨迹滤波，也不改变原始距离。

## 有效 anchor 与维度

软件只使用距离大于 0、并且在当前配置表中具有坐标的 anchor：

- 2D 至少需要 3 个有效 anchor；
- 3D 至少需要 4 个有效 anchor；
- 配置数量默认是 4，但用户可以增加或删除，解算和导出列会跟随配置数量变化。

数量满足并不代表几何条件一定满足。2D anchor 共线、3D anchor 共面或位置过于集中都会使矩阵病态，造成结果不稳定。尤其是所有 anchor 的 Z 相同，无法可靠观测独立高度。

## 未包含的处理

本开源版本不包含 LSTM 或启发式测距纠偏，也不会把 IQ 特征用于修改 SDK 距离。CFR、MUSIC、LOS/NLOS 分数和动态分数仅用于研究分析、质量观察和活动热图。

## 进一步改进方向

- 使用加权最小二乘，将链路质量映射为观测权重；
- 对病态矩阵给出条件数告警；
- 引入鲁棒损失抑制单条异常距离；
- 通过多次迭代、步长限制与收敛判据完善 Gauss–Newton；
- 使用真实标定数据评估算法，而不是把研究特征直接当作测距修正量。
