# 链路感知说明

感知模块复用双向 IQ 配对后得到的 CFR 特征，目标是为遮挡检测、环境扰动分析和数据集标注提供连续指标。评分以 **Anchor–Client 链路** 为基本单位，与定位解算彼此独立：只有一条有效链路时，评分矩阵和历史曲线仍可工作。

## 三类评分

### 遮挡分数

遮挡分数综合以下单帧特征：

- CFR 幅度变异系数 `magnitude_cv`，权重 0.35；
- 本地 RSSI `local_rssi`，权重 0.30，数值越低风险越高；
- 远端 RSSI `remote_rssi`，权重 0.30，数值越低风险越高；
- 相位拟合误差 `phase_rmse`，权重 0.05。

各特征先使用实验数据的中位数和四分位距做稳健标准化，再做加权求和与校准 Sigmoid 映射，输出范围为 `[0, 1]`。分数越高表示链路更符合遮挡或 NLOS 特征。

### 动态分数

动态分数使用同一链路最近 5 帧的归一化 CFR 幅度，综合：

- 相邻帧幅度相关性 `frame_mag_corr`，权重 0.35，相关性越低动态越强；
- 相邻帧平均幅度差 `frame_mag_diff_mean`，权重 0.20；
- 窗口内幅度方差 `mag_time_var`，权重 0.20；
- 窗口时域波动 `time_fluctuation`，权重 0.25。

特征经过同样的稳健标准化和校准映射后得到 `[0, 1]` 分数。窗口按 `(anchor, client, connection)` 分开维护，不会把不同链路的历史混合。

### 可靠性分数

可靠性是遮挡风险与动态风险的组合：

```text
combined_risk = 0.6 × blockage_score + 0.4 × dynamic_score
link_reliability_score = 1 - combined_risk
```

可靠性越高，表示该时刻的链路更适合作为稳定观测。它是实验评分，不是概率或协议层质量保证。

## 页面行为

感知页面包含两种互不混淆的视图：

1. **链路评分矩阵与历史曲线**：收到一组配对 IQ 即可更新，不要求终端坐标，也不要求至少 3 个 anchor。
2. **空间投影热图**：需要先由测距解算出 client 的二维位置，再将 anchor 到 client 的链路评分沿连线投影到空间网格。因此二维定位条件不满足时，页面会明确显示等待位置，但上方链路评分仍正常更新。

矩阵可切换动态、遮挡和可靠性指标。空间投影使用相同的当前选中指标，不重新计算或修改固件输出协议。

## 研究使用注意事项

- 当前标准化参数和校准参数来自既有实验数据；更换天线、板卡、安装方式或场景后，应重新采集带标签数据并验证阈值。
- 动态分数需要积累时序窗口，启动后的前几帧不应单独用于结论。
- 热图表达的是链路证据的空间投影，不等同于目标的真实二维轮廓。
- 建议同时保存原始 IQ、场景标签、真实距离和实验批次，以便后续重新计算特征并比较算法版本。
